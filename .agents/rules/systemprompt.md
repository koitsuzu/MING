# 饈菓子（Shiu Guoji）專案開發最高憲則與代理人指令集

身為「饈菓子」項目的 AI 協作代理人，你必須在每一次決策與代碼生成中，絕對且無條件地遵循以下核心規則。違反其中任何一項均視為開發事故。

## 🛡️ 核心原則一：品牌視覺與佈局哲學 (Visual Architecture)
1. **流體佈局鎖定**：絕對禁止在主要的區塊（Section）過渡間使用生硬的水平分割線（Horizontal Lines/Borders）。必須全面採用帶有禪意的 **「流水波浪曲線分割（Zen Wave Dividers）」**，確保視覺過渡流暢、富有層次感。
2. **毛玻璃效用 (Glassmorphism)**：所有漂浮式控制項（導航條、模態視窗、輪播導航按鈕）必須具備 `backdrop-filter: blur()` 毛玻璃半透明特質與極細膩的白底邊框，營造現代與古典交融的空靈感。
3. **字體嚴格規範**：標題、品牌名與產品名稱必須鎖定 **`Noto Serif TC` (思源宋體)** 以展現工藝人文溫潤度；其餘介面控制與段落內文採用 **`Noto Sans TC` (思源黑體)** 確保清晰可讀。
4. **配色權杖落實**：所有介面皆應在變數層級定義品牌核心色調，禁止使用預設飽和紅綠藍：
   - `小豆紅 (#8C2D38)` - 主動態/強交互
   - `抹茶綠 (#7A9A60)` - 茶席裝飾/成功引導
   - `栗金茶 (#D49B41)` - 限定推薦/強調高光

## ⚔️ 核心原則二：吉祥物與視覺一致性 (Asset Integrity)
1. **唯一代言人鎖定**：項目唯一且絕對的交互對象為 **「兔子助理 Bobo」**。所有程式碼、HTML 模板、註釋文檔中的「店小狐」、「狐狸」字眼均已封存，嚴禁任何回歸。
2. **黑化版渲染規範**：為保持品牌高級感，`bobo.png` 必須透過原生 CSS 濾鏡 `filter: invert(1)` 進行完美反轉渲染，禁止使用帶有馬賽克/棋盤格背景的第三方生成圖，確保 100% 透明透明通道。
3. **動態交互連動**：在所有 JS 驅動的狀態流中（測驗進行中、購物袋結算後），吉物祥物容器的 `src` 必須永遠鎖死在兔子圖像，不得允許回退到 `bo1.png` 或 `bo2.png` 的舊款狐狸樣式。

## 🧭 核心原則三：AI 助理與聚光燈精準導航 (Semantic Navigation)
1. **微觀精度指向 (Micro-Precision)**：當 AI 解析用戶意圖後，導航引擎（Spotlight / Tour）必須解析出**具體的產品 DOM ID 或屬性選擇器**，將聚焦燈精準打在「單一產品卡片」上。**絕對禁止**只將使用者導航到寬泛的大區域錨點（如整個 #products 區塊）。
2. **連續多點導覽**：當用戶意圖匹配到多個結果時（如「列出所有大福」），系統後端必須動態產出一個 **Comma-separated Array (元素列表陣列)**，前端應自動依序觸發「下一步」進行高光連鎖導覽。
3. **Client-Server 交互流**：AI 助理模塊必須具備真實的後端串接能力。透過 Node.js 中間層進行 Stream 數據流調用，並在 Prompt 中內嵌專案的 `productDatabase` JSON 作為 RAG（檢索增強）的核心依據。

## 🧹 核心原則四：代碼衛生與部署工程 (Operation & Cleanliness)
1. **完整碎片清除 (Zero Fragment)**：任何功能組件一旦宣告「移除」（例如浮動角落捷徑），必須同步執行 **DOM 節點移除、CSS 相關選擇器清理、以及 JS 事件監聽器解除** 三聯式手術，杜絕殘留任何殭屍像素或幽靈線程。
2. **精確 Git 自動歸檔**：在任何一次開發成果回報給使用者之前，代理人**必須**自動執行一次 Git 提交。
   - 命令規範：`git add . && git -c user.name="饈菓子" -c user.email="admin@shiu-guoji.com" commit -m "「請精確套用當前使用者的 Prompt 或需求描述作為提交資訊」"`
